## 🟢 Live Project

Oh, you want to know what this is? Fine. I'll explain it slowly.

**AITimeline** is a futuristic, horizontally scrolling web experience that visualizes the evolution of Artificial Intelligence from **2022 to the present — and inevitably, into whatever glorious chaos comes next.**

Inspired by the **TVA's Sacred Timeline** (which, let's be honest, was just a cage), this platform lets you *actually explore* AI history the way it deserves — as the multiverse of madness it truly is.

Each event? A moment reality quietly gave up and let the machines take over.

Each click? Another branch Mobius would have flagged as a nexus event.

Just like Loki navigating the multiverse — *except you probably won't get pruned for this one.* Probably.

## 🧭 The Concept (Pay Attention, This Is Important)

In the Marvel multiverse, **Loki** observes infinite timelines — usually while plotting something spectacular.

In our world, **AI** is creating them — usually while humans insist everything is fine.

**AITimeline** was built for people who understand that:

- AI history is not a boring list of papers
- It's a *series of increasingly dramatic reality shifts*
- Someone needs to document this before the TVA shows up and prunes it

This project transforms AI history into an **interactive visual journey** — because frankly, you weren't going to read a Wikipedia article, were you?

## ⚡ Features (Yes, It Actually Has Them)

### 🧩 Horizontal Timeline Scroll

*For people whose eyes move left to right, unlike certain Asgardian reading habits*

- Scroll **left → right** like a civilized timeline traveler
- Explore AI evolution year by year, event by glorious event
- Smooth futuristic animations that even Kang would find impressive
- Responsive design, because not everyone gets the full screen of the Citadel at the End of Time

---

### 🖱️ Clickable Event Nodes

*Because information doesn't just reveal itself. Even Loki had to ask.*

Click any milestone and uncover:

- **Event title** — the name of the crime against the sacred timeline
- **Release date** — when the branch was created
- **Brief explanation** — a summary for those of you who weren't paying attention
- **Why it matters** — and it does matter, unlike most things you've done
- **Impact level** — rated from *"Hm, interesting"* to *"Nexus Event"*
- **Related links** — for your further investigation, Agent

---

### 🔒 Developer Editing Mode

*Protected from the public, as most powerful things should be*

Only **authorized developers** can edit the sacred timeline. Capabilities:

- ➕ Add new AI milestones
- ✏️ Edit existing events
- 🗑️ Prune nexus events
- 📅 Extend the timeline (obviously, it's still being written)
- 🖼️ Upload images

Access is protected by a **developer authentication code.** Do not try to guess it. It won't end well. For *you.*

## 🛠️ Tech Stack

*Tools fit for building a multiverse. Or at least a very good website.*

| Layer | Technology | Why |
|---|---|---|
| 🎨 UI Framework | React + Next.js | Because someone had to make it fast |
| 🧠 Language | TypeScript | Fewer bugs. No promises. |
| 💅 Styling | Tailwind CSS | Utility-first. Like Loki. |
| ✨ Animations | Framer Motion | Because things should *move dramatically* |
| ⚙️ Runtime | Node.js + Express | The boring but necessary part |
| 🗄️ Database | MongoDB | Documents, naturally |
| 🚀 Deployment | Vercel | Ships like the Bifrost. Fast. |
